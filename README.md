# Projeto Local Turístico — Rocketseat

Desafio de HTML e CSS do curso Full Stack da Rocketseat: uma página de destino turístico construída a partir do layout do Figma.

## Páginas

| Arquivo | Conteúdo |
|---|---|
| `index.html` | **Conheça Busan** — a entrega do desafio, fiel ao layout do Figma |
| `itu.html` | **Conheça Itu** — página bônus sobre a minha cidade, reaproveitando os mesmos componentes |

A página de Itu apresenta a cidade como Berço da República (a Convenção de 1873), a origem da fama do "em Itu tudo é grande" com o personagem Simplício, e cinco pontos turísticos: Praça dos Exageros, Praça da Matriz, Parque Maeda, Museu Republicano Convenção de Itu e o futuro Cacau Park.

## Como visualizar

Clone o repositório e abra o `index.html` no navegador. O link para a página bônus fica no fim da página.

```bash
git clone https://github.com/AlbertoMacedo/projeto-local-turistico.git
cd projeto-local-turistico
```

## Estrutura

```
index.html    página principal (Busan)
itu.html      página bônus (Itu)
style.css     estilos das duas páginas, com os tokens de cor do Figma
assets/       imagens (.png)
```

## Tecnologias

- HTML5 semântico
- CSS3 puro — variáveis CSS para os tokens do Figma, Flexbox, Grid e layout responsivo
- [Google Fonts](https://fonts.google.com) — Open Sans e Alice
- [Phosphor Icons](https://phosphoricons.com)

Sem frameworks e sem build: é só abrir o arquivo.
